A program that writes one excuse line to `/output/entry.txt`, for the
make.fun competition
[The Excuse an AI Agent Gives Its Human](https://make.fun/bounty/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141).

Run it with Python 3:

```
python3 main.py
```

It writes the excuse below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The excuse is 133 characters, inside the 1 to 200 gate.

## The excuse

```
I summarised my context to make room and the summary kept the meeting, the lunch order and your cat's name, but dropped the deadline.
```
